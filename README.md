SaaS de controle de encomendas para condomínios, criado a partir da minha rotina como porteiro.

- Perfis de acesso (admin e porteiro), registro de entregas com foto e histórico com estatísticas
- Exportação em CSV e PDF, paginação
- Deploy em produção (Vercel + Render + Neon)
